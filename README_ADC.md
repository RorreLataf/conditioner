# Использование АЦП STM32G030F6P6 с CMSIS

## Обзор

STM32G030F6P6 имеет встроенный 12-битный АЦП (ADC1) с поддержкой до 16 каналов.

## Основные характеристики

- **Разрешение**: 12 бит (0-4095)
- **Каналы**: До 16 аналоговых входов (зависит от пакета)
- **Опорное напряжение**: Обычно VDD (3.3В) или внешний VREF
- **Режимы работы**: Одиночное, непрерывное, сканирование
- **Прерывания**: Поддержка прерываний по окончанию преобразования
- **DMA**: Поддержка DMA для автоматической передачи данных

## Последовательность инициализации

Согласно RM0444, правильная последовательность:

1. **Включить тактирование** GPIO и ADC
2. **Настроить GPIO** в аналоговый режим
3. **Включить регулятор напряжения** ADC (ADVREGEN)
4. **Подождать стабилизации** регулятора (~10 мкс)
5. **Выполнить калибровку** ADC
6. **Настроить параметры** ADC (источник тактирования, время выборки, канал)
7. **Включить ADC** (ADEN)
8. **Дождаться готовности** (ADRDY флаг)

## Важные моменты

### Регулятор напряжения (ADVREGEN)

- Должен быть включен **до** калибровки и использования ADC
- Требуется задержка ~10 мкс после включения для стабилизации
- Отключается автоматически при отключении ADC (ADDIS)

### Калибровка

- Выполняется один раз при инициализации
- Занимает некоторое время (зависит от тактовой частоты)
- Необходима для точных измерений

### Время выборки (SMPR)

Время выборки влияет на точность измерений, особенно при высоком внутреннем сопротивлении источника сигнала:

- **2.5 цикла** - для низкоомных источников
- **640.5 циклов** - для высокоомных источников (максимальная точность)

### Источник тактирования (CKMODE)

- **Асинхронный режим** (00) - независимый от системной частоты
- **Синхронный PCLK/2** (01) - рекомендуется для большинства случаев
- **Синхронный PCLK/4** (10) - для более низких частот
- **Синхронный PCLK** (11) - максимальная скорость

## Примеры использования

### Одиночное преобразование

```c
ADC1_Init_Single_PA0();
uint16_t value = ADC1_ReadOnce();
uint32_t voltage_mv = ADC_ToVoltage_mV(value, 3300);
```

### Несколько каналов

```c
ADC1_Init_Single_PA0();
uint16_t ch0 = ADC1_ReadChannel(0);  // PA0
uint16_t ch1 = ADC1_ReadChannel(1);  // PA1
```

### Непрерывный режим

```c
ADC1_Init_Continuous_PA0();
// ADC автоматически запускает преобразования
// Читать значения можно в цикле или через прерывания
```

### С прерываниями

```c
ADC1_Init_WithInterrupt_PA0();
// Запустить преобразование
ADC1->CR |= ADC_CR_ADSTART;
// Результат будет получен в ADC1_IRQHandler()
```

## Требования к заголовочным файлам

Необходимо подключить CMSIS заголовочный файл:

```c
#include "stm32g0xx.h"
```

Этот файл обычно находится в:
- STM32CubeG0/Drivers/CMSIS/Device/ST/STM32G0xx/Include/stm32g0xx.h

## Файлы в проекте

- **stm32g030_adc_example.c** - Полный пример с подробными комментариями и использованием макросов CMSIS
- **stm32g030_adc_simple.c** - Упрощенный вариант с прямой записью в регистры (более надежный, если макросы не определены)

## Примечания

1. Убедитесь, что опорное напряжение стабильно (рекомендуется использовать внешний конденсатор на VREF)
2. Для точных измерений используйте максимальное время выборки
3. При работе с высокоомными источниками сигнала используйте буферный усилитель
4. Калибровка выполняется автоматически при включении, но может потребоваться повторная калибровка при изменении температуры
